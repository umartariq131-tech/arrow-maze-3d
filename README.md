# Arrow Maze 3D — Website Game

A responsive, no-install browser puzzle game. It uses a 3D-style interface and HTML/CSS/JavaScript (no external libraries).

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Tap/click arrows with an unobstructed path to the board edge.
4. Restart, generate a new maze, use hints, or try the daily challenge.

## Publish free with GitHub Pages
1. Sign in/create account at https://github.com
2. Click **New repository**. Name it `arrow-maze-3d`; choose **Public**; create repository.
3. Open repository → **Add file** → **Upload files**.
4. Upload `index.html` (README optional). Click **Commit changes**.
5. Open **Settings** → **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Branch: **main**, folder: **/(root)** → **Save**.
8. Wait a minute, refresh the Pages screen. Your site URL will look like:
   `https://YOUR-USERNAME.github.io/arrow-maze-3d/`
